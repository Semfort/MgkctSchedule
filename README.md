# Расписание МГКЦТ (группа 89) — .NET MAUI, Android

## Установка
1. Visual Studio 2022 (17.8+) или 2026 с нагрузкой **«.NET Multi-platform App UI development»**.
2. Создать проект **.NET MAUI App** (не Blazor) с именем **MgkctSchedule**
   (имя важно: от него зависит namespace `MgkctSchedule`).
3. NuGet → установить пакет **HtmlAgilityPack**.
4. Скопировать из архива в проект:
   - `MainPage.xaml` и `MainPage.xaml.cs` — заменить существующие;
   - папки `Models`, `Services`, `ViewModels` — добавить целиком.
   Остальные файлы шаблона (App, AppShell, MauiProgram) не трогать.
5. В `.csproj` оставить только Android, чтобы не собирались лишние платформы:
   `<TargetFrameworks>net10.0-android</TargetFrameworks>`
   (версия net10.0 / net9.0 / net8.0 — какая стоит в шаблоне, её и оставить).
6. Запуск: телефон с включённой отладкой по USB или эмулятор → F5.

## Что внутри
- `Services/ScheduleParser.cs` — разбор HTML (таблица группы, подгруппы, аудитории).
- `Services/Bells.cs` — звонки: будни, суббота, сокращённые. Время правится здесь.
- `Services/ScheduleService.cs` — загрузка страницы и кэш в JSON на телефоне.
- `ViewModels/` — логика экрана, подсветка текущей и следующей пары.
- `MainPage.xaml(.cs)` — экран, полоса дней, свой календарик.

## Управление
- Полоса Пн–Сб, стрелки ‹ › — неделя, свайп по списку — день.
- 📅 — календарь, «Сегодня» — вернуться.
- ⚙ — переключатель «Сокращённые звонки» и выбор подгруппы (запоминаются).
- Потянуть список вниз — обновить с сайта.

## Виджет 2×2 (Android)
Файлы: `Platforms/Android/Widgets/ScheduleWidgetProvider.cs`, `Platforms/Android/Resources/**`,
`Services/WidgetLogic.cs`, `Services/WidgetBridge.cs`.
Подключение: скопировать папку `Platforms` в проект (слить с существующей), `Services` и
`ViewModels` заменить, пересобрать и установить. Затем: долгое нажатие на рабочем столе →
Виджеты → «Расписание 89».
- Идёт пара: показываются она (подсвечена) и следующая.
- Иначе: 3 ближайшие пары (если сегодня всё кончилось, то завтрашние).
- Обновляется в начале и конце каждой пары, при обновлении данных и смене настроек.
- Нажатие открывает приложение. Учитывает подгруппу и сокращённые звонки (только на сегодня).

## Окно настроек и уведомление «Пары на завтра»
- ⚙ на главном экране открывает отдельную страницу `SettingsPage`: подгруппа, сокращённые звонки,
  галочка «Пары на завтра», кнопка пробного уведомления.
- Уведомление приходит в момент окончания последней пары дня (с учётом подгруппы и звонков).
  В субботу, или если завтра нет пар, в нём будут пары ближайшего учебного дня.
- Перед отправкой приложение пытается скачать свежее расписание (8 секунд), без сети берёт сохранённое.
- Будильники восстанавливаются после перезагрузки телефона и обновления приложения.
- На Android 13+ при установке галочки появится запрос разрешения на уведомления.
- Страница сайта может содержать несколько недель (текущую и следующую) - парсер берёт все.

Новые файлы: `SettingsPage.xaml(.cs)`, `ViewModels/SettingsViewModel.cs`, `Services/AppSettings.cs`,
`Services/NotifyLogic.cs`, `Services/NotificationBridge.cs`,
`Platforms/Android/Notifications/TomorrowNotifier.cs`, `Platforms/Android/Resources/drawable/ic_notify.xml`.
Изменены: `MainPage.xaml(.cs)`, `ViewModels/MainViewModel.cs`, `Services/ScheduleParser.cs`, `Services/ScheduleService.cs`.

## Подгруппа
На главном экране под кнопками: одно нажатие переключает Все → Первая → Вторая (с анимацией).

## Выбор группы (80–100)
Настройки → «Группа». Приложение скачивает страницу и разбирает **только выбранную** группу.
У каждой группы свой кэш (`schedule_<группа>.json`), поэтому при возврате к уже открытой группе
расписание показывается сразу, а затем обновляется. Список групп: `ScheduleService.AvailableGroups`.

## Расписание преподавателя
Фамилия преподавателя в карточке пары подчёркнута и нажимается. Открывается его расписание
(та же неделя/дни, подсветка текущей пары работает). В карточках вместо преподавателя указана группа и подгруппа.
Вместо кнопки подгруппы показывается «‹ К группе N» (подгруппа на преподавателей не влияет);
системная кнопка «назад» тоже возвращает к группе.
Расписание преподавателя не сохраняется на диск: живёт в памяти и удаляется при выходе.
Страница: `.../personnel/for-teachers/weekly-timetable?teacher=Фамилия+И.+О.`
